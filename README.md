📱 Smart BMI Calculator (Android)
A clean, modern, and user-friendly BMI (Body Mass Index) Calculator built for Android. This app features "Smart Logic" to handle different height units and provides real-time health category feedback using a dynamic UI.

✨ Features
Smart Unit Detection: Automatically detects if height is entered in Centimeters (e.g., 175) or Meters (e.g., 1.75).

Pro UI Design: Uses CardView with elevation and rounded corners for a modern look.

Dynamic Feedback: The result card changes color based on the health category:

🔵 Blue: Underweight

🟢 Green: Normal Weight

🟠 Orange: Overweight

🔴 Red: Obese

Help & Guidance: Includes an interactive Help Dialog with a direct link to health advice on YouTube.

🛠️ Built With
Java - Application logic.

XML - Modern UI layout (Material Design).

Android SDK - Target API 34+.
